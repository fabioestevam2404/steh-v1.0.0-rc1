# STEH MVP 1.0 Release Candidate 2

Release date: 2026-09-02

## Purpose

RC2 converts the RC1 feature baseline into an executable, strictly typed and
reproducibly validated release candidate. It does not expand the agent surface.

## Delivered

- recovered FastAPI startup and test collection;
- synchronized database, API, Pydantic and workflow contracts;
- strict mypy and Ruff compliance;
- injectable LangGraph checkpointer with in-memory unit tests;
- hardened, checksummed Semgrep/Gitleaks/Trivy image;
- full Alembic downgrade-to-base and restore-to-head roundtrip;
- separated unit, integration and E2E validation;
- commit-bound JSON evidence generated by CI and release workflows;
- consolidated acceptance criteria and roadmap.

## Verified baseline

The release candidate requires all 16 criteria in
`docs/MVP-1.0-RC-ACCEPTANCE.md`. The release workflow must complete against the
exact tag commit and retain its `release-validation-evidence` artifact.

## Known limitations

- `HUMAN_REVIEW` does not yet expose an approval API or checkpoint resume flow;
- bounded rework is recorded but not connected as an automatic graph loop;
- generated code is not executed by an LLM-controlled process;
- Context Engine, SDD/Test Plan, Issue Analysis and PR Review agents remain
  post-RC2 work;
- RC2 is not a production security certification.

## Promotion

RC2 may be tagged only after its release PR is merged with green CI. Promotion
to `v1.0.0` requires a separate decision and evidence review.
