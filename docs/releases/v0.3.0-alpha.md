# STEH v0.3.0-alpha — Security Layer

## Objective

Make security a first-class domain in the STEH workflow.

## Added

- Security Agent
- STRIDE-oriented Threat Model
- Security Findings
- Severity model
- Finding Status
- Security Review Result
- Security persistence
- Security Gate
- Human Review state
- `/api/v1/tasks/{task_id}/security`
- Security unit/E2E tests
- ADR-004

## Workflow

```text
Request
  |
Requirements Agent
  |
REQ Gate
  |
Architecture Agent
  |
ARCH Gate
  |
Security Agent
  |
Security Gate
  +-- CRITICAL -> BLOCKED
  +-- HIGH -> HUMAN_REVIEW
  +-- otherwise -> COMPLETED
```

## Current security posture

The Alpha intentionally does not yet expose:
- shell
- host access
- arbitrary file writes
- production deployment tools
- implementation agent

The stub security review intentionally flags missing API authentication as HIGH,
therefore demo tasks terminate in `HUMAN_REVIEW`.
