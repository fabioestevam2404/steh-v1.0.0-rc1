# STEH v0.4.0-alpha — Controlled Implementation Layer

## Added
- Implementation Agent
- Implementation Plan
- File Change contracts
- Tool Gateway
- capability policy
- task-isolated workspaces
- path traversal protection
- file size/count limits
- explicit prohibition of shell/subprocess/network/delete
- implementation persistence
- Implementation Gate
- ADR-005

## Workflow

```text
Requirements -> Gate
Architecture -> Gate
Security -> Gate
  |
  +-- BLOCK / HUMAN_REVIEW -> STOP
  |
  +-- ALLOW
        |
        v
Implementation Agent
        |
        v
Tool Gateway
        |
        v
Task Workspace
        |
        v
Implementation Gate
```

Alpha 0.4 deliberately does not execute generated code.
Execution, testing and security scanners are reserved for Alpha 0.5.
